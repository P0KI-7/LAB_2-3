1. Задание:
Разработать программу «Анализ данных сенсора» для обработки температурных измерений. Программа должна:
•	Считывать N измерений температуры в динамический массив
•	Анализировать данные (среднее значение, минимум, максимум)
•	Создавать новый массив со значениями, превышающими среднее
•	Обеспечивать корректное управление памятью
2. Описание алгоритма:
•	Использование динамических массивов и указателей для хранения данных
•	Главная функция с последовательным вызовом всех модулей
•	Функция inputData() для ввода значений в массив через указатели
•	Функция average() для расчета среднего значения температур
•	Функции minValue() и maxValue() для поиска минимального и максимального значений
•	Функция filterAboveAverage() для создания нового массива со значениями выше среднего:
o	Первый проход: подсчет количества элементов выше среднего
o	Второй проход: заполнение нового массива подходящими значениями
•	Корректное освобождение памяти после завершения работы
